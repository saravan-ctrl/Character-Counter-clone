Character Counter

Project Description

The Character Counter is a simple web application built using HTML, CSS, and JavaScript. It allows users to type a message and displays the number of characters entered and the remaining characters in real time.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Simple and user-friendly interface.
- Real-time character counting.
- Maximum character limit of 200.
- Displays the number of characters typed.
- Displays the remaining characters allowed.
- Shows a warning when the character limit is reached.
- Responsive design.

How It Works

1. Enter a message in the text area.
2. The character counter updates automatically.
3. The remaining character count decreases as you type.
4. When the maximum limit of 200 characters is reached, a warning message appears.
5. The application prevents users from entering more than 200 characters.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser.
4. Start typing in the text area to test the character counter.
